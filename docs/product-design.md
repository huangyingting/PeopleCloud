# PeopleCloud 产品与体验设计

## 1. 产品定位

PeopleCloud（人间星图）不是一张把头像钉在地图上的名人列表，而是一座可漫游的中国历史人物星图。用户从时代进入，在地图上发现人物、阅读极短但有信息密度的生平摘要，再沿人物关系或同一地点继续探索。

当前版本的核心承诺：

- 覆盖先秦至清的主要历史时期，不把“全朝代”偷换成唐宋样例。
- 每位人物至少具有生卒时间、身份分类、简介、一个有明确关系语义的地图地点和可点击来源。
- 地图位置表达的是“出生、籍贯、主要活动、任职、都城关联或纪念”等关系之一，不默认声称是出生地。
- Three.js 只增强氛围与关系表达；内容阅读、筛选和选择不依赖 WebGL。
- 桌面、触屏、键盘、降低动态效果和 WebGL 不可用时，都有完整可用路径。

## 2. 核心视觉概念：星河入史

地图像一张深色绢本，人物是悬浮在地理坐标上的星点。当前时代的群星更明亮，选择人物后出现三层反馈：

1. 地图平滑聚焦至人物的关联地点；
2. Three.js 星环扩散，以领域色编码星点，用空间细线呈现邻近分布，并让流光沿明确关系或同领域弧线移动；
3. 右侧“人物卷轴”展开生平、时间、领域、地理关系和来源。

视觉语言采用墨黑、青铜金、朱砂红和月白色。动效短而克制：人物选择产生一圈涟漪，关系弧线带有沿路径移动的流光，选择环缓慢呼吸旋转。开启 `prefers-reduced-motion` 时取消持续旋转、流光位移和相机飞行动画，保留静态关系图。

人物数量增加后，HTML 地图标记仍完整保留，但姓名标签按当前人物、代表人物和屏幕碰撞顺序显示。缩放会提高标签容量，悬停与键盘聚焦会临时揭示被避让的标签；这种做法同时保留地图可读性和 178 个可访问的人物入口。

## 3. 信息架构

### 首屏

- 品牌与一句价值主张。
- “进入星图”主行动。
- 当前收录人数、时代数、类别数三个可信统计。
- “如何阅读这张图”简短说明，提前解释地理坐标语义。

### 星图工作台

- 顶栏：品牌、全局搜索、名人名录、视觉/帮助设置。
- 时代轨道：横向时间轴，可用按钮、键盘和触屏选择；显示朝代年限及当前人数。
- 主地图：密度感知的人物标记、Three.js 领域星点/空间星网/关系流光/涟漪、地图缩放和方位控件。
- 快速筛选：思想、政治、军事、文学、艺术、科技、探索、医学等类别。
- 人物卷轴：姓名、生卒、身份、摘要、代表成就、地理关系、证据置信度、来源和相关人物。
- 名录抽屉：搜索、时代、领域联合筛选，并显示当前结果数；具备焦点圈定和 Escape 关闭。

### 辅助说明

- “关于数据”解释收录原则、非穷尽性和争议处理。
- 来源直接链接至稳定的百科或专业机构页面。
- 页面明确标注本产品为策展型人物样本，不声称穷尽历史人物。

## 4. 关键用户旅程

### 旅程 A：按朝代发现

进入星图 → 选择“唐” → 地图和人数同步变化 → 选择李白 → 查看江油关联点及“出生地（有争议）”说明 → 沿相关人物打开杜甫。

### 旅程 B：按领域检索

打开名录 → 搜索“天文”或选择“科技” → 得到张衡、祖冲之、郭守敬等跨朝代结果 → 选择郭守敬 → 时间轴自动切换至元，地图聚焦大都关联地。

### 旅程 C：键盘与降低动态效果

Tab 进入时间轴 → 方向键/按钮选择时代 → Tab 到地图人物列表或名录 → Enter 打开人物 → Escape 关闭卷轴/名录。系统降低动态效果时直接切换视图，不做长距离飞行动画。

## 5. 响应式策略

- `>= 1100px`：人物卷轴固定在右侧，地图保持完整操作区。
- `700–1099px`：卷轴以窄浮层显示，时代轨道横向滚动。
- `< 700px`：人物卷轴变为底部 sheet，最大高度不超过视口的 58%；地图控件上移，避免被遮挡；名录占满屏幕。
- `<= 390px`：隐藏非必要装饰文案，保留搜索、时代、类别、地图、人物详情和来源的完整路径。

## 6. 非目标与诚实边界

- 本项目不是历史 GIS，不绘制声称精确的历代疆界。
- 当前 178 人仍不是完整人物数据库；完整性指时期和体验覆盖，不指穷尽所有名人。
- 人物关系只在有明确公共知识依据或安全的分类联系时出现；“同朝代/同领域”必须以界面文案区分于师友、亲属等史实关系。
- 不自动播放音频，不要求登录，不收集个人信息。

## 7. Production 验收标准

- 总量至少 175 位；所有声明的历史时期至少 8 位人物，长时期达到数据校验器中的更高覆盖线，且类别不单一。
- 语料校验覆盖 ID、时期、生卒、坐标、地理关系、置信度、简介、成就和 HTTPS 来源。
- 核心状态可由 URL 参数恢复，刷新和前进/后退不丢失所选时代与人物。
- WebGL 或远程瓦片失败时显示可操作的降级界面，不出现空白页。
- 360×800、390×844、768×1024、1440×900 无横向溢出，详情和名录可滚动到最后一个来源链接。
- 键盘焦点可见；抽屉焦点圈定；Escape 能关闭；交互控件具有可辨识名称。
- 首屏避免阻塞式大资源；Three.js 与地图按需加载；生产包有合理分块。
- 单元、语料、构建、端到端和运行时控制台检查全部通过。
