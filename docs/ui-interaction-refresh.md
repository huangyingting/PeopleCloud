# PeopleCloud UI 与互动体验升级

## 目标

本轮升级让“人间星图”从可浏览的地图变成会主动提示下一步的探索工具。视觉仍延续墨色、青金与朱砂体系，但提升控件层级、阅读尺度和交互反馈，不以增加装饰替代信息设计。

## 体验原则

- 地图上的每个动作都给出明确反馈：悬停预览、选择聚焦、时代全景都有不同结果。
- 人物详情不再是阅读终点：用户可前后穿行、随机遇见、回到浏览轨迹，或进入人物对照。
- 新互动继续遵守历史语义：对照展示事实字段，不自动推断因果；关系卡仍区分明确关系与分类发现。
- 桌面与移动端共享完整功能；降低动态效果、键盘、WebGL 降级路径不被削弱。

## 新增互动

### 地图发现

- 人物标记在鼠标悬停或键盘聚焦时展示人物、时代、身份、地点关系与操作提示。
- MapLibre 容器必须占满工作区，人物按钮使用可点击的大命中区；Tab 进入地图后可用方向键切换人物，Enter 打开。
- “聚焦人物”回到当前人物坐标；“时代全景”根据当前筛选结果计算视野，不再只是泛化地显示整个中国范围。
- 标记继续保持可点击、可聚焦的 HTML 控件，Three.js 仅承担视觉关系增强。
- 地图显示可逐级放大的真实山川、城镇、水系与近景道路建筑；“星夜”和“山河”两套色板共用图层，不打断当前视野。
- “3D 地形”使用真实高程，可随时切回平面。环游缓慢旋转当前视野，手动拖动或缩放即停止；系统减少动态效果时不启用。
- 地图空白处也能探索：点击落点显示经纬度、附近跨时代人物与直线距离；“近看此地”进入细节视野。
- 手机落点探索时让人物详情自动收起，避免地图控件与两张浮层争夺空间。
- 现代底图与历史人物数据分开标明：城镇、道路、建筑属于现代地理参考，人物线是关联线而非历史行迹。

### 视觉层级

- 界面使用易读的系统无衬线字体，人物与时代标题保留朱雀仿宋，区分操作界面和历史内容。
- 圆角浮动详情、紧凑分段控件、低饱和墨绿与暖金强调色，让地图成为第一视觉主体。
- 固定顶栏压缩至桌面 56px / 手机 52px（另加安全区域）；时间轴和领域筛选在“时代与领域”面板中按需展开，不改变地图容器尺寸。
- 底图、连线、聚焦、全景、地形与环游收纳进左下角“地图工具”，默认只保留工具入口、缩放 / 指南针与必要的地理口径。
- “专注地图”隐藏详情、筛选面板和顶栏次要操作，保留地图选择与紧凑人物卡；退出恢复此前的筛选展开和手机详情展开状态，不重建地图或改变相机。
- 展开面板支持 Esc 收起并返回触发按钮；地图工具、地点探索与模态对话框优先处理自己的 Esc，不会同时退出专注模式。

### 人物漫游

- 详情面板显示当前人物在筛选结果中的位置，并提供上一位、偶遇一位、下一位。
- 记录最近浏览的人物，形成可回跳的“足迹”；跨时代关系探索也会进入足迹。
- 首页人物卡可直接进入李白，而主按钮仍进入默认策展起点。

### 人物对照

- 从任一人物详情打开对照工作区。
- 可按姓名、身份、地点或时代检索第二位人物，也可从推荐人物快速选择。
- 并排展示时代、生卒、领域、地点语义、简介与代表成就；对照只呈现数据，不制造两人之间的历史关系。

### 主题阅读与个人收藏

- 顶栏“主题漫游”提供唐诗、科学探索与思想对读三条线索，每组四位人物，支持从任意站点开始。
- 当前阅读序列在人物详情顶部呈现导读与进度，上一站 / 下一站有明确首末边界；可打开目录或主动结束。
- 换站保留手机详情展开状态；选择序列以外的人物或时代 / 领域时回到自由探索。
- 人物详情与名录卡片均可收藏，名录“我的收藏”支持相同的检索与筛选；空收藏、无匹配与存储失败分别给出明确提示。
- 收藏仅在本机浏览器存储，刷新后恢复；写入失败不会显示已经收藏的成功状态。

## 验收标准

- 新地图控件、人物漫游、浏览足迹、首页人物卡和对照工作区均可用键盘操作。
- URL 仍同步当前时代、人物与领域；浏览器前进后退仍能恢复状态。
- 390x844 移动视口无横向溢出，详情面板中的漫游控件不遮挡关闭按钮或来源。
- 移动端人物详情默认只占较小区域，并提供明确的展开/收起控制，地图视野与地图控件不能被默认面板遮住。
- 对照对话框具备焦点圈定、Escape 关闭和关闭后焦点恢复。
- 自动化测试覆盖人物漫游、足迹回跳、地图视野控件、对照检索与选择。
- TypeScript、ESLint、单元测试、语料校验、构建、Playwright 与严重级可访问性检查通过。
