# 技术架构

## 分层

```text
人物语料、扩充集与时期配置
        ↓
React 状态层（URL、筛选、选择、抽屉）
        ↓
┌───────────────────────┬────────────────────────┐
│ MapLibre 地理交互层    │ HTML 可访问内容层        │
│ 底图、地形、相机、控件  │ 时间轴、名录、标记、详情  │
└───────────┬───────────┴────────────────────────┘
            ↓
      Three.js 增强层
      星点、弧线、涟漪
```

## 状态所有权

`App` 持有当前时期、人物、类别、搜索、抽屉和帮助状态，并同步到 URL。`HistoryMap` 持有 MapLibre 生命周期、相机、底图风格、地形开关和地点探索状态；`ConstellationOverlay` 仅接收可绘制人物、当前人物与同地点标记偏移，不反向控制业务状态。核心人物与扩充人物分别维护，最后汇入同一只读数组，人物详情和名录均由相同过滤函数生成，避免地图与列表结果不一致。

时代 / 领域由 `ExploreDrawer` 按需呈现，地图工具由 `HistoryMap` 自行展开。`App` 的专注模式通过隐藏详情容器保留面板组件身份，避免丢失展开状态或滚动位置；`.panel-visible` 表示真正可见的详情，隐藏面板不占用地图控件布局。工作区只扣除紧凑顶栏高度，展开筛选不压缩地图，模式切换不重建 MapLibre 实例。

地图的 HTML 标记始终负责点击、键盘和辅助技术入口。屏幕空间碰撞算法只切换姓名标签的可见性，不删除按钮。Three.js 图层批量绘制领域着色点、地理近邻线、选中人物关系弧线与沿弧线移动的光点；地图移动时重建投影几何，动画帧只更新光点和选择环，避免持续分配几何对象。

## 主题阅读与收藏

`data/journeys.ts` 保存有序人物 ID 与编辑导读，不另外复制人物资料或生成虚构行程。`App` 持有当前序列及站点，启动序列时重置领域筛选；选择序列外人物、切换时代 / 领域或浏览器历史会退出序列。人物面板保持组件身份，换站不丢失手机展开状态或导航焦点。

`lib/savedPeople.ts` 使用 `peoplecloud:saved-people:v1` 本地存储键，校验人物 ID、去重，并明确返回读取、解析或写入错误。界面只在写入成功后更新收藏状态；通过 `storage` 事件同步同浏览器的其他标签页。收藏不上传，跨设备也不会自动同步。

## 渐进增强

MapLibre 与 Three.js 通过动态 import 进入独立分块。地图加载前展示语义化加载面板；加载或 WebGL 失败时展示人物地理列表，仍可选择人物。Three.js 初始化失败只关闭星图增强，不影响 MapLibre 和 HTML 标记。

## 地理图层与交互

`lib/mapStyle.ts` 定义同一份矢量图层与两套色板。切换风格仅修改 paint / sky 属性，不重建地图、不重新请求整份样式。数据来源为 Natural Earth 低缩放地形、OpenFreeMap 的 OpenMapTiles 矢量服务及公开的 Terrarium 编码高程瓦片；来源署名保留在地图控件中。

- 真实高程用于 hillshade 与 3D terrain，显示夸张系数为 1.35；近景建筑根据矢量数据的高度挤出。高程请求失败时关闭 terrain / hillshade，并明确提示平面降级。
- 缩放范围为 3–16；“聚焦人物”进入 8.5 级近景，“时代全景”按筛选结果与实际面板尺寸计算边距。
- 点击地理位置使用本地人物全集与 Haversine 球面距离生成附近推荐；`lib/geography.ts` 不依赖在线地理编码，不把推荐连线当作历史旅程。
- 桌面与手机按当前详情面板尺寸调整相机；移动端地点探索会收起人物详情，避免两张卡片互相遮挡。
- 地图和 Three.js 像素比分别限制为 1.5 与 1.75；装饰动画最多约 30 帧每秒。环游仅由用户启动，拖动、缩放、选择人物或系统减少动态效果会停止。
- 地图是现代地理参考，不展示未经考证的古代道路、建筑或疆域。

## Three.js 设计

Three 层使用透明、`pointer-events: none` 的 canvas 覆盖地图：

- 将经纬度经 MapLibre `project` 转为屏幕坐标，再转换到正交相机坐标。
- 粒子和弧线只表现当前筛选集，降低 GPU 负荷。
- 相机移动时按 `requestAnimationFrame` 合并几何重建；材质复用，避免移动时重复编译着色器，仅在容器尺寸改变时重设画布。静止时动画帧只更新关系流光和选择环，不重复分配几何体。
- DPR 上限为 1.75，密集时期自动缩小星点；页面不可见时暂停并在恢复可见时继续。
- 监听系统减少动态效果的实时变化，取消漂移和脉冲，只保留静态星点与关系线。

## 安全与运行

- 无用户 HTML 注入；内容仅来自类型化本地数据。
- 外链使用 `noopener noreferrer`。
- 生产服务器应设置 CSP、`X-Content-Type-Options: nosniff`、`Referrer-Policy` 和合理缓存；静态托管配置记录在部署文档中。
- 第三方瓦片失败会显示状态提示；高程失败会关闭立体地形，其余失败保留已经可用的底图与本地人物内容。

## 验证矩阵

- 静态：TypeScript、ESLint、生产构建、依赖审计。
- 数据：时期覆盖、字段和关系完整性、URL 与坐标规则。
- 单元：筛选、搜索、URL 状态、年份格式、相关人物排序。
- 组件：抽屉、人物详情、时代/类别切换、无结果状态。
- 浏览器：桌面和移动核心旅程、键盘、焦点、滚动范围、URL 恢复、WebGL/瓦片降级、控制台错误与页面溢出。
- 地理交互：底图切换、实际 pitch / zoom、地形开关、连线开关、附近人物选择、环游与动态减少效果、高程失败。测试分别模拟 TileJSON、空矢量 PBF 与零海拔 DEM，不把 PNG 响应误当作矢量瓦片。
