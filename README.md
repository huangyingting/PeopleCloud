# PeopleCloud · 人间星图

一个以地图、时间和人物关系探索中国历史名人的沉浸式 Web 应用。当前收录 248 位人物，覆盖先秦至清末的 14 个时期与 8 个领域；本轮为每个时期等量新增 5 人。MapLibre 负责可交互地理底图，Three.js 负责领域星色、空间星网、选择涟漪与关系流光；核心内容、筛选和人物选择始终保留可访问的 HTML 交互。

## 本地运行

```bash
npm install
npm run dev
```

## 质量门禁

```bash
npm run check
npm run test:e2e
npm run verify:sources
```

`npm run check` 会依次执行 TypeScript、ESLint、单元测试、人物语料校验和生产构建。
`npm run verify:sources` 是需要联网的独立审计，检查所有人物来源链接是否可访问；为避免让离线构建依赖外部站点，它不并入 `npm run check`。

地图不再只是低分辨率背景：OpenFreeMap 矢量数据提供城镇中文标注、水系、道路与近景建筑，Mapzen / AWS 高程瓦片提供真实起伏地形。支持星夜 / 山河底图、2D / 3D 切换、近景缩放、比例尺、指南针与可暂停环游，无需配置地图 API key。底图是**现代地理参考**，不代表历史疆域；道路与建筑也不作历史复原。

点击地图任意位置，可按直线距离发现附近的跨时代人物，并继续近看此地或打开人物。人物连线可独立开关；连线表达人物关联，不代表实际行迹。地图会按屏幕空间自动避让人物标签，但不会移除人物按钮；放大、悬停、键盘聚焦或选择人物时都能看到相应标签。Tab 可进入地图人物，方向键切换焦点，Enter 打开人物；滚轮缩放，右键拖动调整方向与倾角。

移动端人物详情可展开或收起，点击地点探索时自动让出地图空间。开启系统“减少动态效果”后，关系流光停止，环游不可启动；手动拖动或缩放也会停止环游。地理服务不可用时会显示提示，高程失败自动切换平面地图，人物内容不依赖外部地理服务。

界面默认采用紧凑布局：时代与领域合并为顶栏的展开面板，底图和相机设置收纳到“地图工具”，地图不再被固定时间轴挤压。“专注地图”可一键隐藏详情和次要控件，退出时恢复人物详情与筛选面板原有的展开状态；当前人物、筛选、地图风格与相机视野不会被重置。Esc 优先收起当前浮层，再退出专注；专注时仍可选择地图人物，再从紧凑人物卡展开详情。

探索工作台支持标记预览、人物聚焦与时代全景、上一位/偶遇/下一位漫游、最近浏览足迹，以及跨时代人物对照。人物对照可检索第二位人物，并从对照结果直接回到星图继续探索。

“主题漫游”提供 **诗里见大唐、仰观与求证、如何安顿此心** 三组编辑阅读序列，可从任意一站开始、逐站阅读或随时结束。序列不是历史行旅路线，也不暗示人物相识或直接传承。人物详情与名录均支持收藏；“我的收藏”可继续按时代、领域和关键词筛选，记录只保存在当前浏览器，刷新后仍可恢复，不需要账号或后端。
